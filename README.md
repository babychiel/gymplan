# Gymplan

Jadwal gym mingguan pribadi — 5 hari latihan (fat loss + core) dengan:

- animasi stick-figure SVG untuk tiap gerakan (43 gerakan)
- checklist per set, tersimpan di browser dan reset otomatis tiap Senin
- timer istirahat sesuai preskripsi tiap gerakan
- timer HIIT 40 detik kerja / 20 detik istirahat, 4 putaran otomatis
- menu makan harian kurang lebih 2050 kkal

Situsnya satu file HTML statis tanpa dependensi. Buka `index.html` atau lihat versi live-nya lewat GitHub Pages.

## Jadwal

| Hari | Fokus | Durasi |
|---|---|---|
| Senin | Upper body strength | 55-60 menit |
| Selasa | Lower body strength | 55-60 menit |
| Rabu | HIIT / conditioning | 35 menit |
| Kamis | Full body push-pull | 55-65 menit |
| Jumat | Steady-state cardio | 50-60 menit |
| Sabtu | Active recovery | 20-30 menit |
| Minggu | Full rest | — |
